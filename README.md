# SEGViC LOGISTICS SERVICES Website

A responsive, corporate one-page website built with:
- HTML5
- CSS3
- Vanilla JavaScript
- The supplied SEGViC fleet photographs

## Included sections
Home, About, Services, Corporate & Contract Haulage, Fleet, Routes & Coverage, Why Choose Us, Gallery, Request a Quote, Contact and Footer.

## Quote form
The form validates required fields and opens the visitor's default email app with a prepared enquiry addressed to:
segviclogisticservices@gmail.com

For a production website, the form can later be connected to Formspree, EmailJS, a PHP endpoint, or a WordPress form plugin.

## Before going live
1. Replace the text "S" logo mark with the official company logo when supplied.
2. Add official phone/WhatsApp numbers when supplied.
3. Replace "Office address: to be provided" with the exact office address.
4. Add the final domain and hosting.
5. Connect a real server-side form/email service if direct web submissions are required.
6. Compress the images further if the hosting provider has strict page-speed limits.

## Run locally
Open `index.html` in a modern browser, or serve the folder with any simple local web server.
